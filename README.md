# PA-S1: Продуктовая аналитика RetailRocket

## Описание проекта
Анализ поведения пользователей e-commerce платформы RetailRocket для улучшения конверсии и удержания.

## Датасет
RetailRocket E-commerce Dataset (Kaggle). Содержит события (view, addtocart, transaction), свойства товаров и дерево категорий.

## Структура проекта
- `data/` - исходные CSV файлы
- `notebooks/` - данный Jupyter Notebook
- `README.md`, `requirements.txt`, `.gitignore`

## Как запустить
1. `git clone <url>`
2. `pip install -r requirements.txt`
3. Поместите CSV-файлы в папку `data/`
4. Откройте `jupyter notebook notebooks/pas1.ipynb`
